# Invoice-Discount-Performance-Dashboard

This project focuses on building a Power BI dashboard to analyze invoice, discount, vendor, and procurement performance data for a simulated business environment. The objective was to provide actionable insights into spending trends, vendor performance, discount utilization, payment terms, and procurement efficiency while implementing advanced Power BI data modeling, DAX calculations, performance optimization, and security concepts. The project also emphasized report optimization and scalable analytics practices using Power BI best practices.

## Skills and Tools Covered:
* Power BI Dashboard Development
* Data Modeling and Relationship Management
* Power Query Data Transformation and Cleaning
* DAX Measures and Calculated Columns
* Time Intelligence Functions 
* KPI and Procurement Performance Analysis
* Trend Analysis
* Performance Optimization using Performance Analyzer
* DirectQuery Optimization Techniques
* Row-Level Security (RLS) Implementation
* Interactive Visualizations and Reporting
* Tools & Technologies: Power BI, DAX, Power Query

## My Learning
This project involved developing a Power BI dashboard to analyze procurement, invoice, and discount performance data within a business environment. The work included data import, transformation, cleaning, data modeling, and relationship management across multiple datasets such as invoices, vendors, locations, currencies, and invoice line items.

The project focused heavily on implementing DAX measures and time intelligence calculations such as YTD, QTD, MTD, prior year analysis, and Year-over-Year (YoY) comparisons to support business performance tracking and decision-making. Additional KPI measures were developed to evaluate invoice counts, discounts, payment terms, spending trends, and vendor performance.

The project also emphasized Power BI performance optimization techniques including the use of variables, Performance Analyzer, DirectQuery optimization, and efficient data modeling practices. Row-Level Security (RLS) was implemented to restrict data access based on user roles and business requirements.

This project strengthened practical skills in Power BI dashboard development, data modeling, DAX calculations, performance tuning, business intelligence reporting, and secure enterprise reporting practices.
